# PS-700 Teludens entry-shell design brief

## Outcome

The root URL is the recognizable Plenum product entry. It must work without a Project or Session identifier, disclose only the authenticated Principal and Organization context, and lead users toward Studio, Session, and authorized Operations destinations. Existing deep links remain authoritative.

## Users and jobs

- An unauthenticated user recognizes Plenum and reaches institutional sign-in.
- An authenticated user confirms their account and Organization, then chooses a workspace.
- A keyboard or screen-reader user reaches the same controls, states, and recovery actions.
- A disconnected user sees no cached protected context and can retry safely.

## Visual direction

Use Teludens v1.3 Institutional Instrumentalism: Graphite continuous materials, Mineral Sage only for decision paths and authenticated commitment, restrained boundaries, compact geometry, and explicit Node / Branch / Path / Gate / State structure. The official catalog wordmark is the only platform identity.

## Constraints

WCAG 2.2 AA, 320 CSS-pixel minimum width, 200-percent text reflow, reduced motion, forced colors, server-authorized context, no Project or Session disclosure, and no UUID required at entry.
