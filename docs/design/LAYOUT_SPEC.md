# Entry-shell layout specification

The shell owns document scroll. Its header is a continuous surface containing the responsive wordmark, theme control, and text-labeled connection state. The main surface is capped at 75rem with a semantic introduction followed by a three-region workspace: navigation Node, empty-workspace Gate, and account Branch.

At 52.01–70rem the compact workspace navigation remains visible and the Access context becomes a focus-managed sheet. At 70.01rem and wider with 44rem or less available height, the Access context also becomes a sheet so the bounded catalog remains primary. At 52rem and below, Workspaces and Access become mutually exclusive labeled disclosures while the work region remains first in the task flow. At 200-percent root text, regions reflow and horizontal document overflow is prohibited. Mobile shell padding respects device safe areas. Studio and Runtime retain their existing internal scroll ownership.

The wordmark preserves its 2170:725 aspect ratio between 7.5rem and 10.5rem. The catalog dark asset is visible on light materials and the light asset on dark materials.

## PS-710 Project portal

The existing shell keeps document-scroll ownership. Inside the central workspace, use one vertical Path: current Organization, search/status Gate, create branch, recent Project cards, Simulation Template cards, and the Admin-only member branch. Project metadata uses a responsive two-column definition grid; at narrow width all toolbar, filter, metadata, and action regions collapse to one column without nested scrolling.

## PS-720 lifecycle portal

Release and Session filters, catalogs, selected details, creation form, and administration navigation remain in the shell's single document scroll. Catalog rows use a flexible content/action split that collapses to one column below 48rem. Digests wrap without forcing horizontal overflow; detail metadata follows the existing responsive definition grid.
