# Security and recovery matrix

| Risk/control | Prevent | Detect | Recover | Evidence task | Production gate |
|---|---|---|---|---|---|
| Cross-tenant access | Trusted context, composite keys, forced RLS | Real app-role pooled-connection tests | Revoke context, investigate Audit Records | PS-110 | ADR-015/Security Owner |
| Session information leak | Default-deny policy and filtered projections | Negative role/field/route tests | Revoke, invalidate cursors, record incident | PS-210 | REQ-047 |
| Duplicate or stale mutation | Stable Command IDs, versions, authority epoch | Receipt/evidence reconciliation | Receipt lookup and explicit merge | PS-120 | ADR-001 |
| Lost/rewritten evidence | Append-only triggers, chained Ed25519-signed Checkpoints, external signer port and body-free independent Anchor metadata | Offline verification rejects modified, missing, reordered, untrusted-key and unanchored history | Restore export plus retained public keys and custodian records; verify before use; correct only by compensation | PS-510/530 | Local signed restore PASS; PS-550 must verify genuinely separate institutional KMS/HSM custody and independent custodian deployment |
| Malicious Plugin | Restricted publisher, signature/digest, rootless read-only container, no capabilities, no-new-privileges, bounded resources/output and default-deny egress; no direct stores | Scan, contract tests, failed Model Run record and real air-gap execution evidence | Kill failed run; suspend/revoke; preserve provenance | PS-220/230 | Confirmed ADR-018 and accepted OPEN-029 baseline; formal Security Owner review |
| Unapproved model effect | Compiled effect allowlist and mandatory Approval Decision bound to proposal hash, target version, Release and epoch | Effect receipt, Command Receipt, Evidence Event and provenance export | Reject/return/stale proposal; no state change; exact receipt replay | PS-230 | DEC-54 |
| Secret Ballot exposure | Version 1 production secret ballots disabled; separate choice store and filtered evidence remain defense-in-depth | Log/export/plugin leak tests | Disable affected Polls; preserve evidence; incident response | PS-240/550 | OPEN-028 resolved for restricted version 1 scope |
| Voice grant abuse | Short credential, Stage/role re-evaluation, one Floor lease | Provider/API cross-boundary tests | Revoke/mute/remove; leases expire | PS-250 | ADR-017 |
| Recording/transcription without consent | Version 1 production recording/transcription disabled; default-off and consent controls remain defense-in-depth | `CONSENT_REQUIRED`, append-only mutation denial, participant projection, and atomic withdrawal/stop Evidence tests | Disable processing; no version 1 production assets should exist; preserve incident evidence | PS-320 | OPEN-027 resolved for restricted version 1 scope |
| Lost offline device | Minimal AES-GCM-protected projection/outbox, non-extractable browser key and credential expiry | Raw-store, wrong-scope, corruption, expiry, revocation and other-role tests; `docs/ps-500-offline-threat-model.md` | Revoke server access immediately; clear on reconnect; retain encrypted drafts no more than 30 days for same-Participant reauthentication; no remote-wipe claim | PS-500 | Resolved OPEN-014/015 policy; managed-device and expiry/retention enforcement evidence pending |
| Dependency or secret exposure | Lockfile, scanning, environment-scoped secrets | CI scans and log review | Rotate/rebuild/revoke | PS-550 | REQ-051 |
| Database/object loss | Encrypted database/object backup with digest manifest and external key reference | Quarterly and pre-major-release clean-target restore drill with Evidence proof verification | Restore to clean target within RTO ≤4 hours and RPO ≤15 minutes; forward-fix incompatible schemas | PS-530 | Local synthetic drill PASS at 9-second RTO and 2-second RPO; institution-owned backup location, key custody, schedule and authorized recovery exercise remain production gates |
| Authority loss | Explicit fencing; no auto-failover | Health and receipt lookup | Operator transfer procedure | Future approval under OPEN-016 | OPEN-016 |

RPO, RTO, retention, key custody, anchor ownership, credential lifetime, and incident owners are not invented here. Their absence blocks production readiness but not bounded local implementation tests.
