# TELUDENS Interface System v1.3 — Institutional Instrumentalism

Open `index.html` in a modern browser. No build step or dependencies required. v1.3 continues the Graphite / Mineral Sage material identity, retains the v1.2 seven-system expansion and Plenum reference slice, and adds interactive institutional workspace, document, material/type and subtraction audit specimens.

## Files
- `index.html` — full design catalog and interactive institutional specimens
- `styles.css` — material, responsive, print, motion and institutional visual rules
- `app.js` — interactive catalog and additional institutional specimen behaviors
- `tokens.json` — existing graphite/sage token source; v1.3 additions currently live as semantic CSS mappings
- `docs/` — five institutional v1.3 design specifications

## Prototype boundaries
Institutional examples are illustrative. Navigation sections in the new workspace specimen change heading and selection but do not load different datasets. Print record invokes browser print and an institutional print stylesheet. The Plenum reference remains a demonstration, not live authenticated software.

## Quality status
JavaScript syntax and file packaging can be checked automatically. Full browser accessibility, visual, contrast, cross-browser and responsive regression validation remains required before shipping production components.
