# Teludens Interface System v1

This package operationalizes the Teludens design direction above the project-agnostic `UNIVERSAL_DESIGN_STANDARDS.md`.

## Files

- `TELUDENS_DESIGN_LANGUAGE.md` — identity, semantic materials, signals, density, component philosophy, Node/Branch/Path/Gate/State grammar.
- `EXPERIENCE_PHYSICS.md` — interaction timing, interruption, reversal, continuity, async feedback, focus, scrolling, reduced motion.
- `SPATIAL_GRAMMAR.md` — geometry, application shell, panels, density dimensions, responsive transformation, scroll ownership.
- `TELUDENS_TOKENS.json` — primitive, semantic light/dark, spacing, radius, density, and motion tokens.
- `PLENUM_REFERENCE_SLICE.md` — canonical Plenum baseline before broader redesign.
- `FIGMA_LIBRARY_SPEC.md` — page architecture, variable collections, component inventory, and QA contract for the Teludens Figma library.

## Implementation order

1. Import/create tokens.
2. Build foundations and documentation.
3. Build core controls.
4. Build navigation/shell and overlay primitives.
5. Build operational components.
6. Assemble the Plenum reference slice exclusively from approved components where reusable patterns exist.
7. Validate Focus / Standard / Operations density.
8. Validate motion, accessibility, and performance.
9. Only then propagate shared patterns across the wider Plenum product.
