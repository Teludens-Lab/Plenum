01 · FOUNDATIONS

One identity. Multiple products.

Teludens sits above universal interface quality standards and defines the opinionated identity, behavior, geometry, and product feel shared across Teludens tools.

01

Calm computational power

Capability is deep; presentation stays quiet. Complexity is organized, not dramatized.

02

Structure before decoration

Hierarchy comes from geometry, typography, tone, boundaries, and state before ornament.

03

Direct manipulation

Objects preserve continuity through state change. Selection, ownership and context do not teleport.

04

Progressive density

Focus, Standard, and Operations use the same architecture at different information compression levels.

05

Consequence-aware UI

Information, interpretation, intention, action, and consequence remain perceptually distinct.

06

Motion communicates causality

Movement answers what changed, where it came from, and what it now affects.

02 · COLOR

Material first. Signal second.

Warm neutral materials create the working environment. Electric Vermilion is scarce and consequential. Brand signal, error, status, and information never collapse into one color.

SIGNAL / DECISION

Electric Vermilion is not “the primary color.”

It marks the current path, active decision, execution point, or meaningful brand moment. Generic primary actions remain neutral; destructive actions remain Crimson.

05 · MOTION

Motion is system feedback.

Routine interaction stays below 300ms. Motion must communicate causality, continuity, orientation, feedback, or hierarchy—and remain interruptible.

07 · CONTROLS

Action semantics before visual emphasis.

The component API separates neutral primary authority, consequential decision actions, secondary controls, quiet actions, and destructive semantics.

12 · GUIDANCE

Rules that protect the system.

A design system is a behavior contract, not a screenshot archive. The catalog exposes the reusable rules; runtime products still need accessibility, performance, keyboard, responsive, and reduced-motion validation.

DO

Preserve object continuity.

Selection, inspector context, scroll position, and proposal identity should survive state transitions whenever the mental model survives them.

DO

Reserve signal.

Strong color and motion should mean something. A0–A2 content does not get promoted with animation.

AVOID

Card mosaics.

Prefer continuous working surfaces, aligned lists, panels, tables, rails, and contextual inspectors over repeated floating rectangles.

AVOID

Generic motion.

No scale-on-hover, persistent floating, decorative bounce, queued transitions, or motion without causality.
